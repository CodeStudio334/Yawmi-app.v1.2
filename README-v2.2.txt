YAWMI v2.2 - واجهة جديدة ولوحة أدوات واضحة

التغييرات: لوحة رئيسية ببطاقات مباشرة، قائمة أدوات تشمل 12 وظيفة، أرشيف تغذية، وزن وتقارير مع منحنى وزن، إدارة الروتين، سلة أساتذة، قارئ كاميرا عند دعم BarcodeDetector وإدخال يدوي بديل.

قبل النشر: احفظ نسخة JSON احتياطية. ارفع محتويات مجلد yawmi-pwa إلى جذر مستودع GitHub Pages. حدث الصفحة/أغلق التطبيق وافتحه لإعادة تحميل ملفات Service Worker.

Supabase: لا تغييرات SQL في هذا الإصدار. البيانات تستخدم الحالة الحالية والمزامنة القائمة. اختبر الاستعادة والمزامنة على نسخة تجريبية أولًا.

قيود: إشعارات الخلفية غير مفعلة، PDF عبر نافذة الطباعة، الباركود بالكاميرا مشروط بدعم المتصفح، لم يتم اختبار iPhone وSupabase الحي.
